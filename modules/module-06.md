# Network Media

## Three Media Types

The media provides the channel over which the message travels from
source to destination. Modern networks primarily use three types of
media to interconnect devices:

- **Metal wires within cables**: Data is encoded into electrical
  impulses.

- **Glass or plastic fibers within cables (fiber-optic cables)**: Data
  is encoded into pulses of light.

- **Wireless transmission**: Data is encoded via modulation of
  specific frequencies of electromagnetic waves.

Generally network media is chosen by four main criteria:

- **Distance**
- **Environment**
- **Speed**
- **Cost**

### Common Network Cables

- **Twisted Pair Cable**: Most commonly encountered type of networking
  cable. Wires are grouped in pairs and twisted together to reduce
  interference. The pairs of wires are colored so that you can
  identify the same wire at each end. Typically one of the wires is a
  solid color and its partner is the same color striped onto a white
  background.

- **Coaxial Cable**: One of the earliest types of networking cable. It
  is mostly used in cable TV. It is also used for connecting various
  components which make up satellite communication systems. It has a
  single rigid copper core that conducts the signal, the core is
  surrounded by a layer of insulation, braided metal shielding, and a
  protective jacket. It is used as a high-frequency transmission line
  to carry high-frequency or broadband signals. TV coax uses screw-on
  F-connectors. They lock tight, keep the shielding unbroken, and hold
  the impedance steady.

- **Fiber-Optic Cable**: It can be either glass or plastic with a
  diameter about the same as a human hair and it can carry digital
  information at very high speeds over long distances. Electrical
  interference does not affect the signal because light is used
  instead of electricity. Fiber-optic cables are also used in
  communication, medical imaging, medical treatment, and mechanical
  engineering inspection. Its very high bandwidth carries very large
  amounts of data. It is also used
  extensively by telephone companies.

## Assessment Questions

1. A security station several hundred meters away needs high speed for
   video surveillance. Which cable?  
   Ans: Fiber-optic.

2. What are two common media used in networks?  
   Ans: Copper and fiber

3. Which type of network cable is commonly used to connect office
   computers to the local network?  
   Ans: Twisted-pair cable

4. Which three factors should be considered when choosing the
   appropriate network media?  
   Ans: The amount of data and the data transfer rate desired. The
   distance between hosts that the media will connect, and the
   environment in which the media is installed.

5. What makes fiber preferable to copper cabling for interconnecting
   buildings?  
   Ans: Greater distances per cable run, limited susceptibility to
   EMI/RFI, and greater bandwidth potential.

6. Which type of network media carries data encoded into electrical
   impulses?  
   Ans: Copper cable

7. Which type of network media carries data encoded into impulses of
   light?  
   Ans: Fiber-optic cable

8. A network administrator in a small office is upgrading the local
   network within the building. New network cables are needed to
   connect office computers and networking devices. Which network
   media should administrator use?  
   Ans: Twisted-pair cable

9. What is the purpose of using twisted pairs of wires in an Ethernet
   cable?  
   Ans: To reduce interference
