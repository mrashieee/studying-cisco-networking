# Checkpoint Exam

1. Which two OSI model model layers have the same functionality as two
   layers of the TCP/IP model?  
   Ans: Network and transport

2. Match TCP/IP model layer to the function.  
   Ans: Network access: controls hardware devices and media that make
   up the network.  
   Internet: determines the best path to forward data through the
   network.  
   Application: represents data to the user, data encoding, and dialog
   control.  
   Transport: supports communication between diverse devices across
   networks.  

3. Which statement defines a data communications protocol?  
   Ans: A set of rules that govern the communication process.

4. Match the protocol function to the description while taking into
   consideration that a network client is visiting a web site.  
   Ans: Application Protocol: Governing th way a web server and a web
   client interact.  
   Transport Protocol: Managing the individual conversations between
   web servers and web clients.  
   Internet Protocol: Taking the segments from transport protocol,
   encapsulating them into packets, and assigning them with
   appropriate addresses.  
   Network Access Protocol: Preparing packets to be transmitted over
   the network media.

5. Which three elements do all communication methods have in common?  
   Ans: Message source, message destination and transmission medium.

6. Which three layers of the OSI model map to the application layer of
   the TCP/IP model?  
   Ans: Session, presentation, and application

7. Which three acronyms/ initialisms represent standards organizations?  
   Ans: IETF, IEEE, and IANA

8. Which two applications are suitable for deploying coaxial cables?  
   Ans: To connect a TV set to the wall plug at home and to connect
   various componennts in a communication system.

9. Which data encoding technology is used in fiber-optic cables?  
   Ans: Pulses of light

10. What two characteristics describe an Ethernet cable?  
	Ans: 4 pairs of twisted cables and color coded pairs of cables.

11. Which type of network cable is commonly used in backbone networks
    and telephone companies?  
	Ans: Fiber-optic cable

12. Two issues of fiber optic media?  
	Ans: Fiber-optic is more expensive than copper cabling and
    requires different termination and splicing expertise from what
    copper cabling requires.

13. Which criterion can be used to select appropriate type of network media?  
	Ans: The environment where the selected medium is to be installed.

14. How much data can be encapsulated into a normal sized Ethernet
    frame before it is sent over the network?  
	Ans: 46 to 1500 bytes

15. Which information does a switch use to populate the MAC address table?  
	Ans: The source MAC address and the incoming port.

16. Which term refers to the process of placing one message format
    inside another message format?  
	Ans: Encapsulation

17. Which type of address does a switch use to build the MAC address
    table?  
	Ans: Source MAC address.
